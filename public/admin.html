CSV 내려받기

평균은 회피한 위원을 빼고 계산합니다. 동점은 분야별 동점자 처리 순서(아이디어: 문제 정의 → 창의성, 해커톤: 실제 구현·작동성 → 업무개선 효과, PoC: 업무개선 효과 → 실제 구현·작동성)로 정합니다. 2차 해커톤·PoC는 작동 검증 통과(채점 위원 과반이 4개 항목 모두 통과로 판정)한 작품만 수상합니다. 같은 결과물이 2개 분야에서 수상권이면 점수가 높은 분야에서만 수상하므로 이 경우는 직접 확인하세요.

심사위원 명단

한 줄에 한 명씩 적습니다. 명단을 저장하면 심사위원 접속 화면에서 성함을 목록으로 고르며, 명단에 있는 성함만 접속할 수 있습니다. 비워 두면 접속 코드를 아는 사람이 성함을 직접 입력합니다.

심사 구분

위에서부터 진행 순서입니다. 평가 방식: "기획안 서면"은 해커톤·PoC의 구현 항목을 "구현 계획의 실현가능성"으로, "발표·시연"은 "실제 구현·작동성"으로 평가합니다. 작동 검증을 켜면 해커톤·PoC 심사표에 [서식 3] 작동 검증표가 붙고, 검증 미통과작은 진출·수상에서 빠집니다. 제출된 심사표가 있는 심사 구분은 삭제할 수 없습니다.
